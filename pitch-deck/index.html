The Problem

Every team shipping LLM agents has a blind spot.

  • Prompt injection — silent override of system instructions (AML.T0051)
  • Tool abuse — unauthorized filesystem/exec spikes (AML.T0063)
  • Context exfiltration — AWS keys, JWTs, secrets in model responses (AML.T0057)

MITRE ATLAS catalogues dozens of these techniques. Your SIEM doesn't see them. Your LLM observability tool tracks cost, not security.

There is no SOC for AI today.

The Opportunity

Built around ClickHouse's prize criteria.

1 · Data Scale

Every LLM event is captured. 200-agent fleet = 0.5–1.7B events/day.

2 · Query Latency

Sub-100ms on 5M rows. Materialized views + per-minute partitions.

3 · Insight → Detection

Real-time alerts with MITRE ATLAS labels. Not just charts.

Sentinel Stream scores 5/5 on all three — by design.

What We Built

Sentinel Stream = the detection layer for the agent era.

  • Ingest every prompt, tool call, retrieval, model response
  • Store in ClickHouse — MergeTree + materialized views, per-minute partitions
  • Detect 3 rule families in real time
  • Alert with MITRE ATLAS labels + forensic event chains in <2s
  • Investigate via natural-language query (sandboxed, template-constrained)

Detection — 3 Rule Families

All three shipped. All three pass evals.

1 · Prompt Injection

AML.T0051 + AML.T0064

12 regex patterns covering direct overrides, jailbreak keywords, [SYSTEM]/[ADMIN] tags, base64 payloads.

<5ms / event

2 · Tool Abuse

AML.T0063

MV-backed 5-min rolling baseline per (agent, tool). Triggers at 3× baseline; critical at 5×.

<50ms / check (11× faster than raw)

3 · Context Exfiltration

AML.T0057

AWS keys, JWTs, SSNs, PEM keys, Stripe/GitHub/Slack tokens + LLM classifier (cached).

<10ms regex · <2s LLM
